- 用户已确认默认Mail 1＋Mail 2；SOP四阶段及直接回复全部保留，指定阶段或真实回复优先。四封不意味着默认全写或自动排期。

- SOP的“已复核待发送”只表示内容状态，不是发送授权。发送状态另记。当前Skill止于本地草稿；用户另行明确要求发送时向适用邮箱流程交接，不因SOP文字启动发送。
- 整个SOP留原文，只在本地适配文件明确项目差异；不把未读取的V1.0原件或发送Skill说成本轮已验证。

Skill负责完整写作与逐封复核，可在项目内显式按路径使用。批次人工检查点先按规范保存；自动批次检查器、角色TOML及统一调度handoff在后续智能体开发阶段实现，当前不声称具备这些功能。必要机械检查先提供精确词数工具，避免将“数词通过”写成内容质量通过。
