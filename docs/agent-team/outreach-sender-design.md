# 发送开发信智能体：简单版

2026-10-22：用户明确要求按简化方式实现。本文件取代先前复杂设计，旧稿已保存在validation-evidence/2026-10-22-simple-sender/。

## 范围

一个发送Agent，加一个批次脚本，复用阿里云邮箱Skill。用户确认邮件清单和时间后，启动本地程序等待，到点按顺序发一封、记录结果、等待30秒，再发下一封。电脑和进程必须持续运行。

- 同公司联系人合写，每阶段一封；Mail1与Mail2分别按用户安排。
- 发件人为ai-long@mytio2.com，完整文字签名加ChinaCoat图片。
- 每封发送前后保存简短结果。SMTP接受不等于最终送达。
- 发生异常或部分收件人拒绝就停止，不自动重试或恢复。
- 中断后人工核对，明确剩余范围及时间后建新批次。

## 明确不做

不做账户锁、跨批次去重索引、复杂状态系统、自动恢复、常驻服务或逐封强制Sent核验。同时只运行一个批次，由主对话协调。结果文件仅防止误重跑同一个批次，不承诺跨批次自动防重。

## 实现位置

- `.codex/agents/outreach-sender.toml`：发送角色。
- `skills/aliyun-email/SKILL.md`及`references/simple-batch.md`：简单执行约定。
- `skills/aliyun-email/scripts/send_batch.py`：检查清单、等待、逐封调用与结果保存。
- `skills/aliyun-email/scripts/email_cli.py`：复用既有阿里云Skill的邮件构建/连接实现，最小补充联合收件地址、结构化发送结果及指定签名。

## 验证

通过虚构地址、模拟SMTP和可控时钟验证顺序、30秒间隔、异常即停、部分拒绝、重复运行拒绝及输入变更。真实发送和后台长时间等待必须在具体用户授权任务中验证；开发完成不自动发送客户邮件。
