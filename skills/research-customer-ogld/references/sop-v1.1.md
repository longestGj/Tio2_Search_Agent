# 客户商业背景调查 SOP

OGLD 四维调查  钛白粉与色母粒业务

版本 V1.1    日期 2026年10月21日    适用项目 MYtio2及色母粒客户开发

目标是回答四个商业问题：这家公司是否真实且主体明确，实际做什么，是否可能采购我们的产品，以及应联系谁、下一步核实什么。每次调查完成一家公司的完整报告，再进入下一家。

### 适用范围与交付边界

适用于主动开发客户和收到询盘后的背景调查，覆盖生产商、分销商、贸易商及终端加工企业。产出为一份有证据的公司报告和下一步动作；不据此直接认定付款能力，也不自动发送开发信。

### 沿用的工作原则

固定使用 OGLD：Official Website、Google、LinkedIn、Customs Data。客户表、Apollo和邮件中的资料仅作为调查线索。逐项区分事实、企业自述、分析推断与未知；询盘调查不采用销售评分模型。

本版修订：在V1.0基础上加入“所有信息来源网址”和“经确认的公司官网”两项强制要求，并同步更新报告模板、完成标准和交付检查。SOP及客户报告使用Markdown（.md）格式。V1.0为历史版本，后续调查执行V1.1。

### 执行顺序与阶段产出

| 阶段 | 必须完成的工作 | 产出 |
| --- | --- | --- |
| 准备 | 锁定名称、域名、国家和本次目标 | 唯一客户主体及线索 |
| O和G | 检查官网并核实公开背景 | 业务、身份和工厂证据 |
| L和D | 核实人员与贸易记录 | 联系人、贸易证据或缺口 |
| 商业判断 | 判断采购角色与产品适配 | 需求证据、候选方向 |
| 交付复核 | 记录结论、疑点和下一步 | 完整报告及跟进任务 |

### 执行责任

调查执行者负责检索、证据留存和初步判断；业务负责人复核身份、需求与联系对象；技术负责人核对拟推荐牌号及其TDS。小团队可由同一人承担，但仍应逐项复核。

## 01  准备与证据记录

### 输入最少信息

建立客户ID，记录公司名、国家、官网或邮箱域名、线索来源、调查日期、执行者，以及本次是主动开发还是询盘调查。只有截图时先提取信息，保留原图；名称不足以唯一定位时，不合并同名公司。

询盘另记：发件人、工作邮箱、RFQ编号与日期、产品、规格、数量及单位、收货地或目的港、交期、认证要求和贸易条件。缺项列为待问问题，不自行填补。

### 主体匹配规则

将公司法定名称、商号、品牌、母公司、子公司和工厂运营主体分开记录。依据注册号、域名、地址、电话或明确的集团关系匹配；相同名字或相似标志不足以确认是同一企业。

### 每项关键结论均建立证据记录

| 字段 | 填写要求 |
| --- | --- |
| 证据ID与调查维度 | 例如 O01、G01、L01、D01，用于报告回溯 |
| 主张与原文 | 写清要证明什么；保留必要短摘录或数据字段 |
| 来源与链接 | 发布主体、页面标题、完整URL或文件名及页码 |
| 时间与范围 | 检索日期、内容日期、记录期间、国家或业务范围 |
| 状态与边界 | 按下表标记；记录不能证明的内容和相互矛盾信息 |

| 证据状态 | 使用规则 |
| --- | --- |
| 已核实 | 有可访问原始依据，主体匹配，证据直接支持所写结论 |
| 企业自述 | 官网、企业资料或员工自述；尚缺独立佐证 |
| 分析推断 | 写明依据与推理，不写成客户已确认需求 |
| 待核实 | 资料缺失、过时、仅摘要、付费内容不可见或信息冲突 |
| 发现矛盾 | 保留双方证据，说明影响和所需补充核实 |

Google用于发现来源；搜索摘要不代替原文。多家目录转载同一段介绍，仍算同一来源。旧证据注明日期；企业成立年与品牌创立年可能不同，先核对口径。

### 所有信息来源网址（必填）

报告末尾统一设置“证据目录与所有信息来源网址”，完整列出本次报告实际采用、引用、用于判断、核实、记录矛盾或说明限制的全部来源。正文用证据ID对应目录；不以“官网”“Google”“LinkedIn”“海关数据”等平台名称代替网址，不仅提供不可复制的引用标记。

- 每个网页来源记录发布主体、页面标题、**完整可点击URL**、对应事实、内容日期、访问日期、证据状态和访问限制。网址采用`[完整URL](完整URL)`格式，便于点击及复制。
- 产品、新闻、登记、LinkedIn公司／个人页面、海关主体或交易页面分别提供具体页面地址；网站首页不能代替实际引用的详情页。TDS／SDS同时列文件直链、版本／日期及所引用页码；如有入口产品页，一并列出。
- 同一URL可合并一条并映射多个事实；同一域名下不同页面不能合并为首页。保留决定内容或筛选结果的必要参数，记录会变化的年份、品类等查询条件。无固定记录链接时，提供平台可访问入口、查询条件及记录ID，并注明限制。
- 仅取得搜索摘要、登录受限、付费或访问失败时，仍保留已取得的来源网址，明确未阅读全文及影响；不能把摘要写成原文核实。记录检索词／检索范围，不必列入未采用的无关搜索结果。
- 用户提供的文件、邮件、截图或API结果若没有公开网址，写“无公开URL”，列文件名、文件ID／邮件或记录ID、日期、页码／行号等可定位信息；有原始来源网址则补列。不得编造链接或公开含凭据的临时访问地址。

来源目录模板：

| 证据ID | 支持的事实／用途 | 发布主体与页面标题 | 完整来源URL | 内容日期／版本 | 访问日期 | 状态与限制 |
| --- | --- | --- | --- | --- | --- | --- |
| O01 | 官网主体对应关系 | 待填写 | [完整URL](完整URL) | 待填写或未标注 | YYYY-MM-DD | 已核实／企业自述／待核实及边界 |
| S01 | 原始客户线索 | 文件名或记录名 | 无公开URL；填写可定位ID与页码／行号 | 待填写 | YYYY-MM-DD | 原始线索，非外部核验 |

## 02  官网与 Google 调查

### 经确认的公司官网（必填）

每份报告开头必须单列“经确认的公司官网”，以完整、可点击的网址呈现，不只写域名或在证据目录中隐藏。

1. 打开候选网站，核对首页、About、Contact及法律声明中的公司名称、地址、电话、邮箱域名、注册号等身份信息。
2. 与官方登记、集团官方页面或其他可靠原始来源交叉核对。记录实际匹配的字段和对应证据ID；不要求登记网站必然公布域名，但必须说明网站与目标主体如何对应。公司名相同、搜索排名靠前或Apollo提供的域名不足以单独确认官网。
3. 区分目标公司的官网、集团官网、品牌／部门网站、地区站点与经销商网站。若目标公司没有独立网站，明确写“未确认独立官网”，另列已经核实的集团／品牌页面及其关系。
4. 记录实际访问的完整URL、跳转后的有效地址、核实日期和访问状态；旧域名或跳转另作备注。网址可打开与归属已确认是两个判断，不能互相代替。
5. 证据不足时保留“候选官网／待核实”，说明缺口；不得为了填满字段写成已确认。网站打不开也不直接等于虚假公司。

固定填写表：

| 字段 | 填写要求 |
| --- | --- |
| 经确认的公司官网 | `[完整URL](完整URL)`；未确认时明确写“待核实” |
| 对应主体 | 法定名称／商号／品牌，必要时附注册号 |
| 网站类型 | 公司独立官网／集团官网／品牌或部门网站／地区站点 |
| 核实依据 | 身份匹配字段、交叉来源的完整网址及证据ID |
| 核实日期与访问状态 | 日期；正文可访问／跳转／访问受限等 |
| 其他相关官网 | 集团、品牌、地区站单列，说明关系；没有则写无或未确认 |

### O  Official Website 官网

依次检查首页、About、产品与应用、工厂或生产能力、技术文件、新闻及Contact。将域名、公司名、地址、电话、邮箱和法律声明对应到准备阶段的主体。

至少深入查看与我们业务最相关的产品页面或TDS/SDS，记录具体产品名、用途和原料线索。只出现“coatings”“plastics”等行业词，尚不足以证明采购钛白粉或色母粒。

工厂核查记录实际生产地址、运营公司、产品或工艺、可识别的现场资料及支持文件。官网声称制造、车间照片或ISO标志只能作为线索；办公地址、仓库和注册代理地址不能直接当工厂。

O阶段输出：经确认的官网完整URL、对应主体、核实依据与日期（未确认则标注待核实）、主营产品、生产或分销定位、相关应用，以及工厂证据与缺口。允许写“官网自称生产商，尚未独立核实工厂”。

### G  Google 公开信息交叉核实

优先打开所在地官方企业登记、公开申报或许可资料，再查行业协会、展会、可信媒体、客户及供应商公开资料。英国公司优先使用官方公司登记资料核实法定名称、编号、状态和注册地址；注册记录本身不证明工厂或采购活动。

| 查询方向 | 可复用检索式 |
| --- | --- |
| 主体与域名 | "公司全称"；"公司全称" "国家"；"邮箱域名" |
| 工厂与产品 | "公司名" factory；"公司名" manufacturing；"公司名" TDS |
| 钛白粉线索 | "公司名" "titanium dioxide"；site:客户域名 TiO2 |
| 色母粒线索 | "公司名" masterbatch；"公司名" "blown film" |
| 异常与变更 | "公司名" insolvency；"公司名" acquisition；再核实原始来源 |

公司规模、营收、员工数、成立年必须附来源日期与统计口径。平台估值不能写成审计数据；集团规模不能套用到英国子公司。网站打不开或搜索结果少，不直接等同虚假公司。

### O和G完成标准

公司主体与官网归属已匹配或明确标为待核实，报告开头已列官网字段及依据；所有采用的网页均有完整来源URL；至少记录具体业务或产品证据；工厂结论附证据状态；所有足以改变商业判断的矛盾进入待办清单。

## 03  LinkedIn 与海关调查

### L  LinkedIn 企业与联系人

先匹配企业主页的域名、国家与业务，再检查员工是否仍在目标公司、工作地区和岗位职责。员工数量与活动频率仅作为辅助线索。无法查看完整资料时，写明访问限制，不补猜姓名或职位。

优先寻找技术负责人、采购负责人和Managing Director。技术岗位核实原料或配方职责；采购岗位区分原料采购与IT、工程采购；集团员工需核实目标国家或工厂的权限。销售岗位可作内部转介人，不默认是原料采购决策者。

记录姓名、完整职位、雇主、地区、职责相关性、LinkedIn链接、佐证来源及核实日期。Apollo补充信息单列来源；“邮箱已验证”与“人员适合开发”是两个不同结论。

工作邮箱分为官方公开、本人确认、工具标记已验证、推测待验证、未获取。隐藏邮箱不得猜补；推测邮箱不进入可发送名单。没有合适个人邮箱时，可记录已公开的公司部门邮箱作为转介渠道。

### D  Customs Data 海关与贸易数据

用法定名称、历史名称、地址及已核实的关联公司分别检索。先记录平台、覆盖国家和时间，再核对每条记录中的进口方、出口方、收货方和产品。明确区分海关原始数据、平台整理的提单和聚合摘要。

产品检索结合英文品名、同义词、牌号及当期适用HS编码。钛白粉使用 titanium dioxide、TiO2 等；色母粒使用 masterbatch、colour/color concentrate 等。HS必须按国家、年份和实际成分核实，不能只凭编码确定产品或用途。

| 必须记录 | 重点防止的误判 |
| --- | --- |
| 交易日期、双方名称和地址 | 把同名公司、集团关联方或货代当成目标买家 |
| 商品描述、牌号和HS | 把一般化工品或颜料记录认定为钛白粉 |
| 重量、金额、数量及单位 | 混用毛重、净重、件数和不同币种 |
| 提单或记录ID、运输与国家 | 跨平台重复计数、同日拆单重复累计 |
| 统计期间及数据覆盖范围 | 把不完整记录当全年采购量或实际消耗量 |

仅确认化工进口时，不得写成已采购TiO₂。已证实的进口量仅代表可见记录量，不能直接等同总采购或年用量。出口商不一定是制造商，也不一定是稳定供应商。

无可用数据时写明：检索了什么、覆盖范围、限制和下一步。区分“未检出匹配记录”“仅摘要不可核验”“无访问权限”“未执行”；任何一种都不等于没有进口。

## 04  商业判断与产品匹配

### 先判断客户角色

分别回答：是生产商、贸易商、分销商还是终端加工企业；是否有自有或运营工厂；采购的是原粉、色母粒、改性料还是成品。分销商可能有采购价值，但不能被写成生产厂家；终端有塑料制品也不代表直接采购钛白粉。

### 钛白粉需求核实

记录相关终端产品、配方或工艺证据，以及对遮盖力、白度、色相、分散、光泽、耐候等性能的实际要求。仅依据应用推断需求时，使用“存在评估可能”而非“正在采购”。

候选牌号须形成完整链条：客户具体应用 → 已知性能要求 → 我方该牌号最新版TDS或测试依据 → 仍需验证的适配条件。未知配方、晶型、表面处理、现用牌号或用量时不补猜。替代竞品牌号须保留试验条件，不能宣称直接等效。

### 色母粒需求核实

记录颜色、载体树脂、接收树脂、加工方式、添加比例、浓度或关键性能、最终用途和认证要求。吹膜客户核实膜用途、厚度与分散或凝胶要求；注塑客户核实树脂、制品用途、分散和外观要求。未知项目作为询问项。

区分色母粒制造商采购颜料，与薄膜或注塑企业采购色母粒。黑色色母粒客户不能自动认定有TiO₂需求；白色色母粒业务也不等于已确认直接采购TiO₂。

### 采购量与供应商的证据边界

采购量优先采用客户明确确认或可核实的交易记录，并保留期间、单位和范围。缺少证据写“未知”，不按员工数、工厂面积、主营行业或猜测配方倒推。供应商品牌、原产地、价格和采购频率同样要求直接证据。

### 形成行动结论

| 行动状态 | 适用条件 | 下一步 |
| --- | --- | --- |
| 继续开发 | 主体与相关业务有依据，暂无阻断疑点 | 核实目标联系人及技术评估入口 |
| 先补充核实 | 主体、应用、工厂或联系人仍有重要缺口 | 列出最多3项优先问题 |
| 暂缓开发 | 存在影响合作判断的未解决矛盾 | 通过独立渠道核实具体疑点 |
| 不匹配当前产品 | 现有业务证据与产品需求不匹配 | 写明理由，保留记录 |

上述为行动状态，不使用分数或A/B/C评级。结论必须分别说明公司真实性、业务匹配和采购证据，不能把三者合并成一个“优质客户”标签。

## 05  固定报告模板与交付检查

### 每家公司使用同一报告结构

报告标题：公司名称＋国家＋商业背景调查。开头注明客户ID、调查日期、执行者、调查目的及资料截止日期，并单列“经确认的公司官网”表（完整URL、对应主体、网站类型、核实依据、日期与访问状态）。按下列顺序填写，未知项不得静默省略。

| 报告部分 | 必须包含 |
