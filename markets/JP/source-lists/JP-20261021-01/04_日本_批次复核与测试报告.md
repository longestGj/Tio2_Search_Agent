## 4. 对后续背调有用的发现

- Matsuo、KISCO、大藝産業、渤天商事的已读官网明确列钛氧化物或酸化チタン业务（S29、S31、S32、S33–S34）。这是继续核实供货合作的事实入口，不是采购承诺。
- 東京インキ官网明确展示白色母粒（S17）；需要进一步核实TiO₂来源和采购机制，不能由产品颜色倒推采购量。
- 茨木塗料的受托生产模式意味着要先问原料由谁采购（S08）；产品制造与原料买方可能不同。
- 日本Pigment与PLASiST有共同控股关系（S13、S15）。21家运营主体不等于21个独立采购中心。
- Resino Color官网列堺化学100%持股（S09），后者有自有TiO₂产品（S38）；保留相关企业，同时将集团供应关系作为背调重点。
- 楠本化成旧页无法读取，但当前官网可确认相关颜料商社业务（S35–S36），所以仍能通过候选门槛；其当前TiO₂经营保持未确认。

## 5. SOP首测评价与改进点

**验证了核心核验流程能够产出可追溯名单；尚未验证商业转化效果或全国覆盖能力。**

| 发现 | 下一批改进 |
| --- | --- |
| 原料商具体TiO₂证据与一般行业相关性不同 | 保留“TiO₂证据边界”字段；不得把4家明确经营者与其余候选混写为已知买家。 |
| 同集团运营企业可能有不同采购边界 | 保留主体ID与共同集团标记，后续调查采购中心而非只按域名合并。 |
| 旧页面摘要仍可被检索，但读取失败 | 优先寻找当前官网替代证据；只证明相关业务时不升级TiO₂结论。 |
| 查询和核验交错，未逐轮锁定valid快照 | 下一批每轮保存新增线索数、新增valid数和累计数。本批不作饱和判断。 |
| 主动研究时间未精确记录 | 下一批记录主动计时和暂停区间，再比较单位有效企业投入。 |
| 既有日本名单检索后置完成 | 下一批在首条网络搜索前完成既有文件检索；本批未定位既有日本名单，但不等于已做全CRM去重。 |
| 名单中仍有14条初步线索 | 继续扩充时先处理这些线索；不重复搜索和再次记录相同企业。 |

不修改原SOP正文；以上作为试运行反馈。当前记录质量可以交付，但逐轮统计和计时是明确的流程记录缺口，不将这次测试描述成全部执行指标无缺陷。
