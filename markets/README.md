# 各国市场成果

| 市场 | 目录 | 成果范围 |
| --- | --- | --- |
| 英国 | [GB](GB/README.md) | 公司背调、组织结构、联系人、历史名单及开发信草稿 |

每个国家使用独立目录：`markets/<国家代码>/`。公司成果存放在 `companies/<公司英文标识>/`；原始客户名单及配套核验记录存放在 `source-lists/`，多批次资料按原批次单独归档；国家目录的 `README.md` 汇总文件。

保留报告原始文件名、日期及核验状态。历史批次与后续累计结果不能简单相加。流程技能见仓库的 `skills/` 目录。
